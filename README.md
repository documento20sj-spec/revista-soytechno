# 📖 Revista Corporativa SoyTechno

Corpus documental completo para el proyecto editorial de la revista corporativa **SoyTechno** — Carelys Eljuri.

---

## 📂 Estructura del Proyecto

```
Revista Carelis/
├── 00_Indice_Documental/        ← Índice maestro y catálogo de documentos
├── 01_Documento_Rector/         ← Directriz editorial principal
├── 02_Corpus_Documental/        ← Documentos normativos y operativos
│   ├── B1_Corpus_Permanente/    ← Manuales e identidad editorial
│   ├── B2_Programa_de_Lanzamiento/ ← Guías para el evento de lanzamiento
│   └── B3_Gestion_del_Programa/ ← Planes operativos y financieros
├── 03_Ediciones/                ← Ediciones de la revista
│   ├── 00_Plantillas_Maestras/
│   └── ST-RV-E01_2027-01/      ← Primera edición (Ene 2027)
├── 05_Herramientas/             ← Recursos de producción
│   ├── fuentes/                 ← Tipografías (Lexend, Source Sans 3, JetBrains Mono)
│   ├── presentacion/            ← Presentación del proyecto
│   ├── redaccion/               ← Guías y parámetros de redacción
│   └── src/                     ← Scripts y utilidades
├── 06_Propuesta_Presentacion/   ← Propuesta ejecutiva
└── SoyTechno_logo_vector/       ← Kit de marca (SVG, PNG)
```

> **Nota:** La carpeta `04_Investigacion/` (benchmarks, análisis de mercado, perfiles) se mantiene fuera del repositorio.
